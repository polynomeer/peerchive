운영체제 셸 구현 — 범위를 줄이고 테스트로 확인

운영체제 · 2026-1 · 2인 · 약 25시간 · 🌐 전체 공개

문제
파이프·리다이렉션·백그라운드 실행을 지원하는 셸을 C로 5주 안에 만들어야 했습니다.요약
역할
파서 재설계와 좀비 프로세스 문제 해결을 맡았고 두 역할 모두 팀원 확인을 받았습니다.기여 · 팀원 확인 2
핵심 결정
예외 처리를 덧대는 대신 파서를 상태 기계로 재작성해 실행부와 분리했고, 덕분에 2인이 병렬로 작업했습니다.⚖️ 결정 4/08
근거
백그라운드 실행 후 좀비가 쌓이는 원인을 찾아 회수 방식을 바꿨습니다.🧱 막힘 5/12
결과
직접 만든 테스트 42개를 리눅스에서 모두 통과했고, 잡 컨트롤은 팀 합의로 범위에서 뺐습니다.✅ 검증 6/03⚖️ 결정 5/22
한계
Ctrl+C 시그널 문제는 미해결로 남았고, 테스트 스크립트 기여는 아직 팀원 확인 전입니다.🔁 회고본인 설명 · 미확인

도서관 혼잡도 웹앱 — 실시간 센서 대신 수동 입력

웹프로그래밍 · 2025-2 · 4인 · 약 60시간 · 🌐 전체 공개

문제
열람실 자리가 있는지 가 보기 전에는 알 수 없다는 불편을 다뤘습니다.요약
역할
혼잡도 입력 API와 입력 검증 모듈을 설계했고 팀원 2명이 확인했습니다.기여 · 팀원 확인 2
핵심 결정
센서 연동 승인이 학기 내 어렵다고 보고 사용자가 직접 입력하는 방식으로 범위를 바꿨습니다.⚖️ 결정 10/14
근거
허위 입력을 줄이려고 같은 사용자의 연속 입력 간격을 제한하는 규칙을 넣었습니다.⚖️ 결정 10/30
결과
사용성 테스트 5명 중 3명이 입력 흐름을 막힘 없이 마쳤고 2명은 버튼 위치를 찾지 못했습니다.✅ 검증 11/20
한계
실제 학생 대상 장기 운영은 하지 않아 입력 참여율은 확인하지 못했습니다.🔁 회고

수강신청 시뮬레이터 — 동시 요청에서 정원 초과 막기

데이터베이스 · 2025-1 · 3인 · 약 35시간 · 📄 요약 공개 사후 작성

문제
동시에 신청이 몰릴 때 정원보다 많은 신청이 저장되는 문제를 재현하고 막는 과제였습니다.요약
역할
부하 테스트 스크립트 작성과 트랜잭션 격리 수준 비교를 맡았습니다.기여 · 팀원 확인 1
핵심 결정
격리 수준을 올리는 대신 정원 차감을 조건부 갱신 한 번으로 처리하기로 했습니다.⚖️ 결정 (사후 작성)
근거
동시 요청 200건으로 수정 전후를 비교한 측정 기록이 있습니다.✅ 검증 (사후 작성)
결과
수정 후 측정에서 정원 초과 저장은 나타나지 않았습니다.✅ 검증 (사후 작성)
한계

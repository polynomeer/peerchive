운영체제

가상대학교 컴퓨터공학과 · 3학년 전공 · 개설 학기 기록 2025-1, 2025-2, 2026-1

과목 소개 학생 작성

프로세스, 스레드, 동기화, 메모리 관리, 파일 시스템을 다룹니다. 학기 중 C 언어로 작은 시스템 프로그램을 2~3개 만드는 과제가 있고, 대부분 리눅스 환경에서 직접 시스템 호출을 다루게 됩니다. 이론 시험과 과제의 비중이 비슷하다는 의견이 많았습니다.

선수 개념

학생이 붙인 태그를 운영자가 병합했습니다. 태그를 누르면 같은 개념을 다룬 기록으로 이동합니다(목업에서는 동작하지 않음).

  • C 포인터
  • 리눅스 기본 명령
  • gdb 디버깅
  • fork / exec
  • 파일 디스크립터
  • Makefile

과제 유형

과제 원문이 아니라 수강했던 학생이 직접 쓴 요약입니다. 학기마다 세부 요구사항은 다를 수 있습니다.

  • 셸 구현 개인 또는 2인

    명령어를 읽어 실행하는 작은 셸을 만듭니다. 파이프, 리다이렉션, 백그라운드 실행 같은 기능을 단계적으로 붙이는 형태였습니다. — 2026-1 수강생 요약

  • 동기화 문제 풀이 개인

    여러 스레드가 공유 자원을 쓰는 상황을 직접 만들고 락·세마포어로 경쟁 상태를 막는 과제였습니다. 실행 결과와 설명 보고서를 함께 냈습니다. — 2025-2 수강생 요약

  • 메모리 할당기 실험 보고서 2~3인

    할당 전략 몇 가지를 비교하고 단편화를 측정해 보고서로 정리했습니다. 코드보다 실험 설계와 해석 비중이 컸습니다. — 2025-1 수강생 요약

자주 막히는 지점

공개된 🧱 막힘 기록을 “나도 막혔어요” 수로 정렬했습니다. 해결 방법은 정답 코드가 아닌 개념·접근 설명입니다.

  1. 자식 프로세스가 좀비로 남음

    맥락: wait, SIGCHLD, 백그라운드 실행 · 해결 기록 3건 · 사례에서 보기

  2. 파이프 연결 후 프로그램이 끝나지 않음 (fd 누수)

    맥락: pipe, dup2, close 순서 · 해결 기록 2건 · 사례에서 보기

  3. 따옴표가 섞인 명령어 파싱이 깨짐

    맥락: 토크나이저, 상태 기계 · 해결 기록 2건

  4. Ctrl+C를 누르면 셸 자체가 종료됨

    맥락: 시그널 핸들러, 프로세스 그룹 · 해결 기록 1건 · 미해결 1건

  5. 과제 서버와 내 노트북에서 결과가 다름

    맥락: 컴파일러 버전, macOS와 리눅스 차이 · 해결 기록 2건

“파서부터 테스트 붙이세요”

표시명 ‘커널초보’ · 2026-1 수강

첫 주에 할 일
리눅스 환경부터 맞추고 fork·exec 예제를 직접 돌려 보기.
가장 시간을 잡아먹은 곳
파이프 여러 개를 이을 때 닫지 않은 fd 찾기. 이틀 걸렸어요.
다시 한다면
파싱과 실행을 처음부터 분리하고, 파서 테스트 케이스를 먼저 20개쯤 만들 것.
미리 알았으면 좋았을 것
프로세스 그룹과 시그널 개념. 교재 해당 장을 미리 읽으면 Ctrl+C 처리가 쉬워집니다.

“마감 2주 전이 진짜 시작”

익명 · 2025-2 수강

첫 주에 할 일
팀원과 기능을 쪼개기 전에 전체 흐름을 그림 한 장으로 합의하기.
가장 시간을 잡아먹은 곳
좀비 프로세스. 증상이 바로 안 보여서 늦게 알아챘어요.
다시 한다면
ps로 프로세스 상태를 확인하는 습관을 초반부터 들일 것.
미리 알았으면 좋았을 것
gdb에서 자식 프로세스를 따라가는 설정.

“보고서도 과제의 절반”

표시명 ‘민트초코’ · 2025-1 수강

첫 주에 할 일
평가 기준 공지를 읽고 보고서에 들어갈 항목을 미리 목차로 만들기.
가장 시간을 잡아먹은 곳
실험 결과가 매번 달라서 측정 조건을 고정하는 일.
다시 한다면
측정 스크립트를 먼저 만들고 실험은 나중에.
미리 알았으면 좋았을 것
외부 단편화와 내부 단편화의 차이. 용어를 헷갈려 보고서를 다시 썼어요.

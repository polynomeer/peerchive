사용자 조사용 정적 목업

모든 인물·과제·수치는 실험용 가상 예시입니다. 실제 서비스가 아닙니다.

Peerchive 개발 전 검증 실험(docs/planning/DELIVERY_PLAN.md §2.2)에 쓰는 화면 3개입니다. 기능은 동작하지 않으며, 참여자가 정보 구조와 내용을 읽고 판단하도록 돕는 것이 목적입니다.

목업 목록

  • 1. 과목 페이지 — 운영체제 (가상대학교 컴퓨터공학과)

    E1 족보 대체 테스트

    수강 예정 학생이 선배 노트, 자주 막히는 지점, 워크로드 분포, 공개 사례 스냅샷을 보고 첫 주 계획을 세웁니다. 최종물보다 막힘·선배 노트가 더 유용한지 확인합니다.

  • 2. 공개 사례 — 셸 구현 과제

    E1 족보 대체 테스트 E4 채용자 비교

    진화 보기, 전환점 중심 빌드 로그, 기여 선언과 확인 상태를 보여 줍니다. “학습용 상세 보기”와 “포트폴리오 요약 보기”를 전환해 같은 기록이 두 독자에게 어떻게 읽히는지 봅니다.

  • 3. 공개 프로필 — 김지민 (가상 학생)

    E4 채용자 비교

    채용 검토자가 GitHub 링크와 비교해 케이스 카드, 역량 × 근거 매트릭스를 보고 주요 역할과 근거를 설명하고 면접 질문을 작성합니다.

진행 시 유의 사항

  • 참여자에게 화면이 가상 예시임을 먼저 알립니다.
  • 버튼·링크 일부는 동작하지 않습니다. 눌러 보려는 시도 자체를 관찰 기록으로 남깁니다.
  • 측정 기준은 모집 전에 고정하고 결과에 맞춰 바꾸지 않습니다.

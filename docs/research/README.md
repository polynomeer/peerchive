## 3. 연구 윤리와 데이터 취급

- 모든 참여는 [동의서](consent-notice.md)를 받은 뒤 시작합니다. 언제든 중단·철회할 수 있습니다.
- 과제 파일을 강제로 받지 않습니다. 참여자가 화면을 보여 주는 방식이 기본이며, 파일을 받으면 실험 종료 후 삭제합니다.
- 녹음은 별도 동의가 있을 때만 하고, 요약 작성 후 원본은 삭제합니다.
- 인터뷰 노트·시트에는 이름 대신 참여자 코드(S01, R01, F01, G01)를 씁니다. 코드와 실명 대응표는 운영자 개인 저장소에만 둡니다.
- **이 저장소에는 참여자 데이터·노트·실명·연락처를 커밋하지 않습니다.** 공개 가능한 종합 결과만 익명화해 `docs/research/findings/`에 기록합니다.
- 수동 운영 중 수집한 과정 기록을 Peerchive 공개 사례로 쓰려면 별도 공개 동의를 다시 받습니다.
- 작은 표본의 결과를 일반화하지 않고, 판단 기준은 시작 전에 고정합니다([measurement.md](measurement.md)).

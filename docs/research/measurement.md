# 측정 정의와 판단 기준 (사전 고정)

[검증 키트](README.md) · 관련: [실행 계획 §2.2](../planning/DELIVERY_PLAN.md#22-실험)

이 문서는 **실험 시작 전에 고정**합니다(고정일: 첫 참여자 모집 전). 이후 변경하면 변경 이력과 이유를 아래 §9에 남기고, 이미 수집한 결과에는 원래 기준을 적용합니다.

## 1. 공통 정의

| 용어 | 정의 |
|---|---|
| 기록 | 빌드 로그 1건. 운영자 대필은 작성자 승인 시에만 포함하되 입력 경로를 구분 |
| 기록한 주 | 해당 참여자가 그 주(월~일)에 기록 1건 이상 남긴 주 |
| 작성 시간 | 체크인 7번 자기 보고 + 운영자가 관찰한 표본(가능하면) |
| 활성 참여자 | 첫 주에 기록 1건 이상 남긴 참여자 |
| 시험 기간 | 해당 학교 중간·기말고사 주. 별도 표시하고 분석 시 구분 |

## 2. E0 수동 운영

| 지표 | 계산 | 진행 조건 |
|---|---|---|
| 기록 유지 | 4주 중 3주 이상 기록한 활성 참여자 ÷ 활성 참여자 | 팀 단위로 절반 이상의 팀에서 50% 이상 |
| 작성 부담 | 작성 시간 중앙값 | 5분 이하 |
| 태그 사용 | 태그형 그룹에서 진행 외 태그(막힘·결정·검증) 비율 | 참고(기준 없음) |
| 그룹 비교 | 태그형 vs 자유 기록의 유지율·후배 유용성 평가 | 참고 |
| 디스코드 경로 | 전체 기록 중 디스코드 경로 비율, 옮기기 지연 | 참고(봇 우선순위 판단) |
| 기여 요약 수용 | 종료 인터뷰에서 “도움됨”이라 답한 팀원 비율, 실제 동료평가·발표 사용 팀 수 | 1팀 이상 실제 사용 또는 과반 도움됨 |

미충족 시: 태그 축소, 파일·체크인 중심 흐름, 봇 우선순위 상향(실행 계획 §2.2).

## 3. E1 족보 대체

| 지표 | 계산 | 진행 조건 |
|---|---|---|
| 행동 구체성 | 첫 주 계획에 참고 자료 기반의 구체적 행동이 1개 이상 있는 참여자 수 | 8명 중 5명 이상 |
| 유용성 순위 | 선배 노트 또는 막힘을 최종 결과물보다 높게 둔 참여자 수 | 8명 중 6명 이상 |

“구체적 행동” 판정: 특정 개념·도구·순서·시간 배분을 언급(예: “waitpid부터 실습”). 일반론(“열심히 한다”)은 제외. 판정은 2인이 독립 판정 후 합의.

## 4. E2 사후 작성

| 지표 | 계산 | 진행 조건 |
|---|---|---|
| 완료 시간 | 시작~종료 분 | 5명 중 4명이 30분 이내 |
| 공개 동의 | 요약 이상 공개에 동의한 수 | 3명 이상 |

## 5. E3 사례 정리

| 지표 | 계산 | 기준 |
|---|---|---|
| 작성 시간 | 서식 정리 소요 vs 참여자가 과거 포트폴리오 작성에 쓴 시간(자기 보고) | 단축 여부 |
| 이해도 | 제3자(동료 2명)가 역할·결과를 정확히 말한 비율, 서식 vs 결과물 링크 | 서식이 더 높음 |

## 6. E4 채용자 비교

| 지표 | 계산 | 진행 조건 |
|---|---|---|
| 정확도 | 역할·근거를 정확히 말한 검토자 수 (형태 2) | 5명 중 4명 |
| 질문 구체성 | 구체적 질문 수, 형태 1 vs 형태 2 | 4명 이상이 형태 2에서 더 구체적 |
| 확신도 | 1~5 평균, 형태별 | 참고 |

제시 순서는 참여자마다 교차합니다.

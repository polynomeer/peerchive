# 공급 키트: 선배 노트·막힘 카드·사후 작성 (E1·E2·E6)

[검증 키트](README.md) · 관련: [제품 기획 §8](../PROOFU_EVOLUTION_PLAN.md#8-강의-아카이브-족보의-공개판), [§6.7 사후 작성](../PROOFU_EVOLUTION_PLAN.md#67-사후-작성-모드)

공통 규칙: **답이 아니라 지도를 남깁니다.** 과제 원문·정답 코드·답안 파일, 교수 개인에 대한 평가는 받지 않습니다. 받은 내용은 작성자 승인 없이 공개하지 않습니다.

---

## 1. 모집 메시지

### 1.1 졸업생·고학년 (카톡·메일)

```text
안녕하세요, ○○○입니다. 후배들이 과제를 시작할 때 참고할 수 있는
'과목별 지도'를 만들고 있어요. 정답이나 과제 파일이 아니라,
"이 과목 과제는 어디서 막히고, 얼마나 걸리고, 첫 주에 뭘 해야 하는지"를 모으는 일입니다.

[○○과목]을 들으셨다면 10분만 내주실 수 있을까요?
- 선배 노트: 질문 4개에 짧게 답하기 (10분)
- 여유가 되시면 '가장 오래 막혔던 곳' 1~3개 (개당 5분)
- 더 여유가 되시면 지난 과제 하나를 30분 안에 되짚어 보기

익명으로 남길 수 있고, 공개 전에 꼭 확인받습니다.
폼: (링크)   마감: MM-DD
```

### 1.2 수강 예정 학생 (E1)

```text
다음 학기에 [○○과목] 들을 예정이신가요?
과제 시작 전에 참고 자료를 보고 '첫 주 계획'을 써 보는 15분짜리 실험에
참여해 주실 분을 찾습니다. 과제 내용을 미리 보는 것이 아니라, 선배들의
경험(막힌 곳·시간·조언)을 정리한 화면을 보고 의견을 주시면 됩니다.
사례: (기입)  신청: (링크)
```

## 2. 선배 노트 폼 (10분, E6)

1. 과목명·학교 (자유 입력) / 수강 학기
2. 과제 유형 한 줄 요약 (과제 원문이 아니라 본인 말로: 예 “리눅스 셸을 직접 구현하는 과제”)
3. **첫 주에 했어야 했던 일은?**
4. **가장 시간을 많이 잡아먹은 곳은?**
5. **다시 한다면 다르게 할 것은?**
6. **미리 알았으면 좋았을 개념·자료는?** (자료는 출처 링크로)
7. 대략 총 소요 시간: ~10시간 / ~20시간 / ~40시간 / 40시간 이상
8. 표시 방식: 실명 / 표시명(입력) / 익명
9. 공개 동의: 내용을 확인한 뒤 공개에 동의합니다 / 확인 후 결정하겠습니다
10. ☐ 이 노트에 과제 정답·답안·교수 개인 평가가 포함되어 있지 않습니다.

---

## 3. 막힘 카드 폼 (개당 5분)

1. 과목 / 과제 유형
2. **증상** (한 줄): 예 “fork 후 자식 프로세스가 좀비로 남음”
3. 관련 키워드 (쉼표): 예 프로세스, waitpid, 시그널
4. 오류 메시지 (선택, 경로·이름 등 개인정보는 지워 주세요)
5. **시도한 것** (실패한 것도 좋아요)
6. **해결·우회 방법** — 개념·접근 위주로. 해결 못 했으면 “미해결”
7. 걸린 시간: 30분 미만 / ~2시간 / 반나절 / 하루 이상
8. ☐ 해결 부분이 과제 답(코드·답안) 그 자체가 아닙니다.

## 4. 사후 작성 가이드 (30분, E2)

지난 과제 하나를 다음 순서로 되짚습니다. 운영자가 화상으로 함께하며 **시작·종료 시각**을 기록합니다.

| 단계 | 시간 | 할 일 | 참고 자료 |
|---|---|---|---|
| 1 | 5분 | 과제 한 줄 요약, 기간, 팀 규모, 내 역할 | 제출물, 단톡방 |
| 2 | 10분 | 마일스톤 3~5개와 각 시점의 산출물(있으면 캡처 1장) | 파일 수정일, 커밋 이력, 발표 자료 버전 |
| 3 | 10분 | 기억나는 ⚖️결정 1~2개(선택지 → 기준 → 선택 → 지나고 보니), 🧱막힘 1~3개 | 메신저 검색 |
| 4 | 5분 | 🔁회고: 배운 점, 다시 한다면 / 공개 범위 선택(비공개·요약·전체) | – |

- 모든 항목에 `사후 작성`을 표시합니다. 날짜는 기억·파일 기준의 자기 기입입니다.
- 끝난 뒤 묻기: 가장 어려웠던 단계는? 어떤 자료가 있었으면 더 빨랐을까?

## 5. E1용 과목 허브 프로토타입 준비

1. 첫 과목 하나를 정하고 E6으로 선배 노트 5개 이상, 막힘 10개 이상을 모읍니다.
2. 작성자 승인을 받은 내용만 [과목 페이지 목업](mockups/course.html) 구조에 맞춰 노션 공개 페이지 또는 정적 페이지로 옮깁니다. 목업의 가상 데이터를 실제 내용으로 바꿀 때는 저장소에 커밋하지 않습니다.
3. 비교군으로 같은 과목의 “최종 결과물 링크 모음” 페이지를 준비합니다.
4. 수강 예정 학생에게 두 페이지를 각각 5분 보게 한 뒤 “첫 주 계획”을 5줄로 쓰게 하고, 정보 유용성 순위를 매기게 합니다(선배 노트 / 막힘 / 소요 시간 / 최종 결과물 / 참고 자료).
